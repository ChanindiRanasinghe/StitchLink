# StitchLink

B2B marketplace connecting clothing shops with solo/home-based dressmakers in Sri Lanka.

## Stack
- Frontend: Next.js 15, TypeScript, Tailwind CSS
- Backend: FastAPI, Python
- Database: PostgreSQL

## Structure
StitchLink/
├── frontend/   # Next.js app
├── backend/    # FastAPI app
└── docs/       # Project documentation
