# StitchLink Main System Workflows

## 1. User Registration and Login

1. User selects the required account type.
2. User registers with their basic information.
3. System validates the submitted information.
4. System creates the user account.
5. User logs in using their credentials.
6. System authenticates the user.
7. System identifies the user's role.
8. System provides access to the appropriate dashboard.

## 2. Clothing Shop Creates an Order Request

1. Shop logs into StitchLink.
2. Shop creates a new order request.
3. Shop enters the order requirements.
4. Requirements include clothing category, quantity, deadline, budget, location, description, and reference images where applicable.
5. System validates the information.
6. Order request is published to the marketplace.
7. Suitable dressmakers can view the request.

## 3. Dressmaker Finds an Order

1. Dressmaker logs into StitchLink.
2. Dressmaker browses available order requests.
3. Dressmaker searches or filters orders.
4. System displays relevant order details.
5. AI matching can recommend suitable orders based on the dressmaker's skills, experience, location, capacity, availability, and other relevant factors.
6. Dressmaker selects an order request.
7. Dressmaker reviews the requirements.

## 4. AI-Based Dressmaker Matching

1. Shop creates an order request.
2. System collects the order requirements.
3. System retrieves relevant dressmaker information.
4. Matching system evaluates factors such as:
   - Skills
   - Clothing specialization
   - Experience
   - Location
   - Availability
   - Production capacity
   - Pricing
   - Previous performance
5. System calculates matching scores.
6. Suitable dressmakers are recommended to the shop.
7. Shop reviews the recommendations.

## 5. Quotation Process

1. Dressmaker reviews an order request.
2. Dressmaker decides whether to submit a quotation.
3. Dressmaker enters estimated material costs, labor costs, additional costs, total price, estimated completion time, and notes.
4. System validates the quotation.
5. Quotation is submitted to the shop.
6. Shop receives a notification.
7. Shop reviews the quotation.
8. Shop accepts or rejects the quotation.

## 6. AI-Assisted Quotation

1. Dressmaker enters order requirements and cost information.
2. System collects relevant historical and current data.
3. AI quotation service analyses factors such as order quantity, clothing category, material costs, labor requirements, estimated production time, and historical pricing.
4. System provides an estimated price range and/or suggested quotation.
5. Dressmaker reviews the AI suggestion.
6. Dressmaker can modify the quotation.
7. Final quotation is submitted to the shop.

## 7. Order Management

1. Shop accepts a quotation.
2. System creates an active order.
3. Dressmaker receives an order notification.
4. Dressmaker confirms the order.
5. Order status is updated throughout production.
6. Shop can monitor order progress.
7. System sends relevant notifications.
8. Dressmaker completes the order.
9. Shop confirms completion.
10. Order is marked as completed.

## 8. Capacity Monitoring

1. Dressmaker maintains availability and production capacity information.
2. System records active and completed orders.
3. System calculates current workload.
4. AI capacity prediction analyses workload and historical information.
5. System identifies potential overloading or available capacity.
6. Capacity information can support order recommendations and matching.

## 9. Demand Prediction

1. System collects historical order information.
2. Data is analysed by factors such as clothing category, location, quantity, and time period.
3. AI demand prediction analyses historical patterns.
4. System generates demand forecasts.
5. Forecast information is presented through analytics.
6. Insights can help dressmakers and shops plan future activities.

## 10. Production Risk Detection

1. System monitors active orders.
2. System collects information such as deadlines, progress, workload, and delays.
3. AI risk detection evaluates potential production risks.
4. System identifies possible delays or capacity-related issues.
5. Risk status is generated.
6. Relevant users receive notifications or warnings.
7. Users can take appropriate action to reduce the risk.

## 11. Messaging and Notifications

1. Shop or dressmaker opens an order or conversation.
2. User sends a message.
3. System delivers the message to the relevant user.
4. System records the conversation.
5. Users receive notifications for relevant events.
6. Notifications can include new quotations, accepted orders, order updates, messages, deadlines, and production risk alerts.

## 12. Reviews and Ratings

1. Order is completed.
2. Shop can review and rate the dressmaker.
3. Dressmaker can review and rate the shop.
4. System validates the review.
5. Rating and review are stored.
6. Average ratings are updated.
7. Reviews and ratings can be displayed on user profiles.
8. Reputation information can support future matching.

## 13. Administration Workflow

1. Administrator logs into the administration dashboard.
2. Administrator monitors users and marketplace activities.
3. Administrator can verify users.
4. Administrator can manage user accounts and roles.
5. Administrator can manage categories.
6. Administrator can monitor orders and quotations.
7. Administrator can handle reported issues and disputes.
8. Administrator can suspend or deactivate accounts when necessary.
9. Administrator can view system statistics and analytics.

## 14. Overall StitchLink Workflow

The main marketplace workflow can be summarized as:

Shop Registration
→ Create Order Request
→ Order Published
→ AI Matching
→ Dressmaker Recommendation
→ Dressmaker Reviews Request
→ Quotation Submitted
→ Shop Reviews Quotation
→ Quotation Accepted
→ Order Created
→ Production
→ Progress Monitoring
→ Order Completed
→ Reviews & Ratings

AI services operate throughout the workflow to support:

- Dressmaker matching
- Quotation assistance
- Capacity prediction
- Demand prediction
- Production risk detection
